# Papers

Name paper notes `YYYY-short-title.md` (e.g., `2017-attention-is-all-you-need.md`).

## Lightweight template

```markdown
# Paper Title (Year)

- **Link:** <url>
- **Tags:** #transformers #training

## TL;DR
1–3 sentences in your own words.

## Core Idea
What problem it solves and how.

## Key Details / Equations
Important architecture, loss, or experimental findings.

## Questions & Takeaways
Open questions, limitations, or ideas to try in `experiments/`.
```
