# Hopfield Network on Fashion-MNIST (PyTorch)

## Goal

Implement and train a classical binary Hopfield network in PyTorch following CS 479 Lecture 13 (Hebbian energy minimization, asynchronous recall, and capacity stress test on Fashion-MNIST).

## Setup

```bash
uv sync
```

Run the script or launch Jupyter:

```bash
uv run python train_hopfield.py
uv run jupyter lab
```

## Files

- `train_hopfield.py` — standalone PyTorch implementation (start here)
- `hopfield_lab.ipynb` — interactive notebook for step-by-step experiments
